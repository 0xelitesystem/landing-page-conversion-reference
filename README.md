# Landing Page Conversion Reference

A landing page exists to get one specific action from a visitor: sign up, buy, book, subscribe. It converts when the visitor quickly understands what is offered, believes it is for them, trusts you enough to act, and meets little friction in doing so. Most pages that fail are not ugly; they are unclear, ask for too much, or try to do several jobs at once. This reference covers the few things that actually move conversion, and the honest line around them.
